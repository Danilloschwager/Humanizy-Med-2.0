# Humizanizy-Med-2.0
Humanizy Med é um chatbot de saúde desenvolvido em Python e FastAPI, integrado à Groq API para processamento de linguagem natural. O projeto fornece informações médicas gerais e orientação básica de forma rápida e acessível, utilizando uma arquitetura simples, eficiente e preparada para futuras integrações, melhorias e evoluções e novas melhorias.
